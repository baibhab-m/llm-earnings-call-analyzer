Earnings-Call Analyzer

Pick a company, load its latest quarter, extract fields, score 8 signals, get a view. Real Q1 FY27 numbers for 3 Indian companies ship with the page; paste any other transcript to analyze it the same way.

How it works (the whole architecture)

  1. Input — company + quarter. Either a bundled pack (verified numbers) or your own pasted transcript.
  2. Fetch — tries a live transcripts API if you give a key, else uses the bundled pack. Same fallback pattern as the Python pipeline.
  3. Extract — one fixed "smart prompt" asks an LLM for strict JSON with 8 fields (prompt shown below). With no key, the same 8 fields come from regex rules.
  4. Score — 8 signals, each +1 / 0 / −1, summed. Score ≥ +2 → BUY, ≤ −2 → SELL, else HOLD. Every point is visible in the breakdown table.
  5. Memo — fields table + signal table + one-line reason + view.
